# 009 — The link preview names «Оля Гайдамака»

**Date:** 2026-10-31
**Version:** 26.10.8
**Follows:** 008-2026-10-30-ukrainian-name.md

## What changed

- The link preview's site name (`og:site_name`) reads «Оля Гайдамака», first name first, in place of
  «Гайдамака Оля».

## Why

- The owner chose the organisation's order. The tool belongs to the olya-haydamaka organisation, whose site and
  profile write «Оля Гайдамака»; «Гайдамака Оля» is haydamaka.com's own wordmark, which stays as it is there.

## Details

- `tests/head.test.ts` pins the name, so it isn't copied back from haydamaka.com by mistake. The design documents in
  `docs/` keep the handoff's wording.

## Verification

- The new head test failed on the old tag («Гайдамака Оля») before the change, and passes after it.
- `npm run check` passes, and the build passes. The end-to-end tests were not run: the change is one tag in the page
  head, which no browser test reads.
